Layout audit

Loads the real app in an iframe, resizes that iframe to each target width, and measures the rendered result. An iframe has its own viewport, so the app's own matchMedia breakpoints and its measured Fit 16 pass run for real at every width.

It checks the things a person should never have to report: a heading that appears twice, a label squeezed to nothing, a control too small to hit, text clipped by its own box, a panel wider than the screen, and a fixed element sitting on top of something you need to press.

Reads getBoundingClientRect, clientWidth/scrollWidth and textContent — never getComputedStyle mid-transition, which returns interpolated values and lies. Each width settles before it is measured.

Serve the repository root, then open /fixtures/layout-audit.html: python3 serve.py
