Media decode matrix

Drives the real app's real import path — the same loadSampleFile() a person reaches by choosing a file — and records what actually happened to each one. It does not call decodeAudioData directly, because the question is not "can this browser decode it" but "what does Aura do when it can't".

Fixtures are generated, never downloaded. WAV, M4A, MP4-with-audio, a hand-built MPEG-1 Layer III stream and a RIFF/WAVE declaring an unimplemented codec come from python3 fixtures/make-media-fixtures.py. OGG, WebM and MP4-without-audio are recorded here by MediaRecorder, so they match the browser under test rather than whatever encoder happened to be on a build machine.

Serve the repository root, then open /fixtures/media-decode.html: python3 serve.py
