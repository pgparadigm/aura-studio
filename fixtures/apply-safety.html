Apply safety

Drives the real shipped runtime in a hidden iframe — real drop handler, real Apply buttons, real undo. It asserts the guarantees that protect a singer's work: Replace leaves nothing of the old pattern, Fill Empty destroys nothing, one Apply is one undo step, Discard changes nothing at all, and no analysis data or media ever reaches storage.

Undo depth is measured without reaching into hist — that is unreachable, because app.js is one IIFE with no globals. Instead every write to the save key is watched: autosave() writes exactly the string it snapshots and pushHistory() pushes only when that string differs, so a write whose value differs from the one before it IS a checkpoint. The 4-second autosave timer cannot be suppressed and rewrites an identical string; that is why the assertion is zero distinct writes rather than zero writes.
