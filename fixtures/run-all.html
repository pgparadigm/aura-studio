Every suite, one after another

Runs each browser suite in its own frame, in sequence, and reports what each returned. The point is not speed — it is that a suite's result must not depend on which suite ran before it. Each suite now blanks its app frame and clears the project keys before booting (fixtures/qa-reset.js); this page is what proves that holds when they run back to back.

Suites needing hardware or generated media (midi-qa manual matrix, media-decode without fixtures/media/) report what they can and mark the rest OPEN — that is a correct result, not a pass.
