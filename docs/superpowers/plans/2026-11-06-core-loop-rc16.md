## Architecture (by blocker)

1. **Tempo.** `detectBPM` is NOT changed (the import analyser is locked by Philip's own rule). The my-beat path gets
   its own suggestion: a tempo in the file's name (`…140bpm…`, `140 bpm`, `_140_`) wins; otherwise a fine search
   (5 ms hop, fractional lag) within ±8% of what was detected, then the half/double relative inside 120-160 is
   preferred (trap counted the way FL counts it). The row shows the tempo in effect as the selected chip ("typed" when
   typed). A first take becomes its own undo step (↶ clears it, ↷ brings it back), so ↶ never skips past a recording
   to undo the tempo.
2. **Ask** guidance text wraps to its full length (no ellipsis), at every width.
3. **Song tools** (Architect, Transitions, Finish): an 8 px gap at least, each label whole; One-step undo disabled reads
   at 4.5:1 contrast.
4. **Clip labels:** a readable short name (3 letters or more) when the clip is narrow; the full name on hover (title)
   and long-press (the clip bar names it), never "V…".
5. **The piano roll follows the selected clip:** a bass clip opens the roll on the bass part of that section (the `lo`
   notes, edited in place, one undo step per edit, heard live and in the export); a melody clip, the melody. Enter on a
   bass clip opens it (the clip's own aria text then tells the truth). No empty melody roll after a bass pick.
6. **Export format panel:** WAV 16 / 24 / 32-bit float, 44.1 / 48 kHz; AAC (.m4a, the browser's WebCodecs encoder and a
   small MP4 writer; shown disabled with the reason where the browser has none); MP3 (vendored lamejs, LGPL, its own
   file and licence notice, no fetch at run time). The one-tap default is unchanged (so `e1Saved`, `e2ExportGraph`,
   `e2ExportJitter` keep matching f304607). Save everything is unchanged (project, master, stems at bar 1, vocals as
   32-bit float, the stems add up).
7. **Phone:** Ask and the transport never cover the arrangement's content; Mix opens the mixer; the beat grid shows all
   16 steps of the bar on one screen.
8. **Header:** the release id (`rc.16`), read from `APP_VERSION`.
9. **Microphone:** stays raw; a check pins it.

9. `cl9WavFormats`, `cl9Aac`, `cl9Mp3`, `cl9FormatLimits`, `cl9Mp3Responsive`: every format decodes back in both

10. `cl10PhoneNoOverlay@390,360`, `cl11PhoneMix@390`, `cl12PhoneSteps@390`.

12. `clWalk@1440,390`: beat (named with its tempo) → vocals (Lead, punch-in, Double, a vocal file) → arrangement (start
